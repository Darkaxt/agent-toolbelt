# Cybersecurity Orchestrator

One instruction-only entrypoint for installed security workflows and focused investigation references. It adds no scanner, Python runtime, package dependency or background service.

Copy `codex/skills/cybersecurity-orchestrator` unchanged into the personal Codex, shared agents or Claude skill root. Specialist skills and plugins must actually be available in that environment; installing this router does not install Codex Security in Claude.

The bundle replaces the retired bulk collection with routing to existing maintained capabilities and eight useful topics grouped into four references. References identify concrete interpretation errors and point to primary documentation; they do not certify a detection engine or execute third-party scripts.
