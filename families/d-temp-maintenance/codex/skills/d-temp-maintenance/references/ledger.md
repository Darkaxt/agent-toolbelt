Statuses: `needs_evidence`, `ready`, `executing`, `awaiting_owner`, `verified`,
`partial`, `blocked`, `preserved`. State why an action is blocked and what resolves
it. A preserved path is not a successfully removed target.

Owner requests: record exact existing task ID/title, path, request, dispatch
receipt and retention/cleanup evidence. Deduplicate identical requests. A prepared
prompt is not sent; a delivered request is not completed work.

Final reconciliation: verify exact removed targets and retained state; list pending
actions/residuals; record final free bytes with concurrent growth caveat. Sum only
non-overlapping deletion receipts. File sizes and indexed estimates are not a
physical reclaim guarantee, especially with hardlinks or sparse files.
